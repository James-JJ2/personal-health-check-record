# 健康記錄機器人 Personal Health Check Record

在自己電腦上執行的健康紀錄程式。可以有多位成員（例如「我」和「太太」），每個人的資料、重點項目和回診提醒都分開存放。資料只存在自己的電腦，不會上傳。

## 怎麼用

**推薦：安裝成桌面 App（MacBook、Windows PC 都可以）**
1. 用 Chrome 或 Edge 開 https://james-jj2.github.io/personal-health-check-record/
2. 按頁面上方的「安裝成桌面 App」（或網址列右邊的安裝圖示）
3. 之後從桌面／應用程式圖示開啟，沒有網路也能用，拍照辨識也可以用

**離線檔案版**：按 Code → Download ZIP，解壓縮後開啟 `健康記錄機器人.html`。注意：直接用檔案開啟時，瀏覽器不允許文字辨識，拍照匯入要用 App 版，或改用「貼上文字」。

## 功能

- **重點頁**：每個人自選要追蹤的項目（甲狀腺、血糖、血脂、肝腎功能、血壓體重），顯示最新數值和趨勢曲線
- **回診提醒**：依上次檢驗日期和間隔（1–12 個月）算出下次回診日，可以加入行事曆（.ics，提前一週提醒）
- **用藥劑量紀錄**：醫師調整藥量時記一筆，對照檢驗數值
- **拍照／截圖匯入**：選健保快易通的截圖或報告照片（也可以在電腦上直接 Ctrl+V／⌘V 貼上截圖），自動辨識文字，逐列核對後才存入。辨識程式和繁中字庫都在 `lib/`，不連網
- **貼上文字**：手機在截圖上長按拷貝文字（iPhone 原況文字、Google 智慧鏡頭），貼上後自動整理
- **手動新增**：自費檢驗、居家量測都可以記
- **匯入健康存摺**：健保署健康存摺 XML 或本工具的統計 Excel，整理就醫、用藥、牙科、疫苗與影像、檢驗趨勢
- **匯出 Excel**、深色／淺色

## 資料存在哪裡、兩台電腦怎麼共用

- 預設存在這台電腦的瀏覽器裡
- 按「連結資料檔」建立 `健康記錄資料.json`，之後每次變更自動存檔（Chrome、Edge）。把它放在 iCloud Drive、Google 雲端硬碟或 OneDrive 的資料夾，另一台電腦按「連結資料檔 → 開啟現有資料檔」，兩台就共用同一份資料。兩台不要同時開著修改
- 不支援自動存檔的瀏覽器（Safari、Firefox）：用「下載備份」／「讀取備份」搬資料

## 檔案

- `index.html`、`健康記錄機器人.html`：主程式（內容相同，前者給線上網址和 App 用）
- `健康存摺統計工具.html`（V1.0，2026-11-24）：單檔版健康存摺統計工具，用 Chrome 直接開啟。匯入健康存摺 XML 或統計 Excel 後，依功能與檢驗類別用彩色色塊區分；有偏高／偏低／範圍內分類色塊、每項小趨勢圖、最近日期、「↻ 重新整理資料」、深淺色切換、手機版卡片排版
- `lib/`：Excel 元件（SheetJS）、文字辨識（tesseract.js）與繁中／英文字庫
- `manifest.webmanifest`、`sw.js`、`icons/`：安裝成 App 與離線使用
- `health_bank_to_excel.py`：把健康存摺 XML 轉成含公式的 Excel（`python health_bank_to_excel.py 健康存摺.xml 輸出.xlsx`，需安裝 openpyxl）

## 隱私

這個 repo 只有程式。**請不要把自己的健康存摺 XML、Excel、資料檔或備份放進這個 repo**（`.gitignore` 已排除 `.xml`、`.xlsx`、`.json`、`.ics`）。沒有資料時畫面顯示的是虛構的示範資料。

本工具只整理資料，不提供醫療判讀。拍照辨識可能認錯字或數字，存入前請核對；檢驗結果請與醫師討論。
